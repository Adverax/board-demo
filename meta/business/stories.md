# Stories

## Board (2026-10-24)

US-001: As a team member, I want to see all cards grouped into `todo`,
        `doing` and `done` on one shared board, so that I know where the
        team's work stands.
US-002: As a team member, I want to add a card with a title and an optional
        description that lands at the end of `todo`, so that new work is
        captured in the queue.
US-003: As a team member, I want to edit a card's title and description, so
        that the card stays accurate.
US-004: As a team member, I want to delete a card, so that dropped work
        leaves the board.
US-005: As a team member, I want to move a card one column left or right so
        that it lands at the end of the target column, so that the board
        reflects progress.
US-006: As a team member, I want a refused action to show its reason on the
        page, so that I understand why nothing changed (WIP limit,
        non-adjacent move, invalid title).
